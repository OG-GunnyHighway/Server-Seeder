# Server Seeder

**Version 1.0.0** · Publisher: GH-Experiments

Server Seeder is a free Windows desktop utility that automates Squad server seeding. At a time you schedule, it starts Squad, joins your selected server, waits for players to arrive, then closes Squad and restores your original game settings.

It is a separate companion program, not a Squad mod.

## What it does

- Launches Squad and joins your selected server.
- Monitors the server's player count.
- Ends the session when your configured player threshold is confirmed, or when your maximum duration is reached.
- Runs on a schedule you choose, with optional wake-from-sleep.
- Closes Squad and restores your original game settings afterwards.

## Supported game and server

Squad is the only supported game, and **Unnamed #1** is the only server currently available for seeding. You cannot add your own server in this version.
